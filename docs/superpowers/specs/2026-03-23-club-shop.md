# Bocas Juniors FC — Club Shop Spec

**Date:** 2026-03-23
**Scope:** A `/shop` page listing club merchandise and kit with links out to 3rd-party suppliers. No payment processing on-site. Admin panel gains a Products section for managing the catalog.

---

## Overview

The club sells merchandise through 3rd-party print-on-demand / kit suppliers. The shop page acts as a curated storefront: each product card shows an image, name, description, SKU, and price label, with a "Buy Now" button that opens the supplier's product URL in a new tab.

No inventory, no payment processing, no checkout — the site never touches money.

---

## Data Model

### Supabase table: `products`

| column | type | notes |
|---|---|---|
| `id` | `uuid` | primary key, default `gen_random_uuid()` |
| `name` | `text` | e.g. "Home Kit 2025" |
| `sku` | `text` | unique, e.g. "BJF-KIT-HM25" |
| `description` | `text` | short tagline shown on card |
| `price_label` | `text` | display only — e.g. "$35" or "From £25" |
| `image_url` | `text` | Cloudinary URL |
| `buy_url` | `text` | external link to 3rd-party supplier product page |
| `category` | `text` | `'kit'` or `'merch'` |
| `active` | `boolean` | default `true` — hides product without deleting |
| `display_order` | `integer` | controls sort order in grid; starts at 10, increments by 10 |
| `created_at` | `timestamptz` | default `now()` |

Row-level security: SELECT is public (no auth required). INSERT/UPDATE/DELETE require authenticated session (RLS policy on the table).

## Public Shop Page

**File:** `src/app/shop/page.tsx`
**File:** `src/components/shop/product-grid.tsx`
**File:** `src/components/shop/product-card.tsx`

`shop/page.tsx` is a server component. It fetches all `active = true` products ordered by `display_order asc` from Supabase and passes the full list to `<ProductGrid products={products} />` as a prop. `ProductGrid` is a client component that filters client-side — it never re-fetches from Supabase.

- Page wrapper: `bg-brand-dark min-h-screen`
- `<PageHeader title="Shop" subtitle="Official Bocas Juniors FC merchandise" />`

### Empty state

When there are no active products, `ProductGrid` renders:

```tsx
<p className="text-white/40 text-sm text-center py-16">No products yet — check back soon.</p>
```

### ProductGrid (`product-grid.tsx`)

Receives `products: Product[]` prop. Maintains `filter: 'all' | 'kit' | 'merch'` state. Filters the prop array client-side.

- Filter tabs: **All / Kit / Merch**
  - Active: `bg-brand-primary text-white`
  - Inactive: `border border-brand-border text-white/50 hover:border-brand-cyan hover:text-brand-cyan`
  - Style: `rounded text-xs font-bold uppercase tracking-wider px-3 py-1.5`
- Grid: `grid grid-cols-2 md:grid-cols-3 gap-4 p-6`

### ProductCard (`product-card.tsx`)

- Background: `bg-brand-surface`
- Border: `border border-brand-border rounded`
- Image: `next/image` with `aspect-ratio: 1 / 1`, `object-cover`; placeholder `bg-brand-border`
- Category badge:
  - `'kit'` → `bg-brand-primary/15 text-brand-primary text-[9px] font-bold uppercase tracking-widest px-2 py-0.5 rounded`
  - `'merch'` → `bg-brand-cyan/10 text-brand-cyan text-[9px] font-bold uppercase tracking-widest px-2 py-0.5 rounded`
- Name: `text-white font-black text-sm`
- SKU: `text-white/30 text-[10px] font-mono`
- Description: `text-white/50 text-xs`
- Price label: `text-white font-black`
- "Buy Now" button: `.btn-primary text-xs` — `target="_blank" rel="noopener noreferrer"` — links to `buy_url`
- Hover: `hover:scale-[1.02] transition`

## Admin Panel — Products Section

**File:** `src/app/admin/page.tsx` — add products fetch and render `<ProductsAdmin>`
**File:** `src/components/admin/products-admin.tsx` ← new

The existing admin page is a server component that checks auth via `supabase.auth.getUser()` and redirects to `/login` if not authenticated. Follow this same pattern — no change to the auth mechanism.

Add to the parallel data fetch at the top of `AdminPage`:

```ts
const products = await getAllProducts() // new server action
```

Pass products down:

```tsx
<ProductsAdmin products={products} />
```

`ProductsAdmin` is a client component added as a new `<section>` at the bottom of the admin page (below the existing MediaUploader section). No tab navigation — consistent with the existing layout pattern.

### ProductsAdmin component

**Product list table** columns: Name · SKU · Category · Price Label · Active · Order · Actions

- **Active toggle**: inline boolean toggle; calls `toggleProductActive(id, active)` server action on change
- **Edit**: clicking Edit replaces the add form with an edit form pre-populated with that product's data
- **Delete**: `window.confirm()` prompt before calling `deleteProduct(id)` server action
- **Order**: up/down arrow buttons to move a product one position earlier/later; calls `reorderProducts(orderedIds)` server action. No drag-and-drop dependency required.

### Add / Edit form fields

| field | input |
|---|---|
| Name | text |
| SKU | text |
| Category | select: kit / merch |
| Price Label | text |
| Image URL | text |
| Buy URL | text |
| Description | text |

New products default to `active: true`. The active flag is not shown in the add form — it is toggled via the Active column in the product list table. The edit form follows the same fields as the add form (active state is managed separately via the toggle).

Labels: `text-brand-cyan font-bold uppercase tracking-wider text-xs`
Inputs: `.input` class (dark background, brand-border, white text)
Submit button: `.btn-primary w-full`

## Server Actions

**File:** `src/app/actions/products.ts`

All actions use `createSupabaseServiceClient()` — consistent with existing admin actions in `src/app/actions/admin.ts`. Auth is enforced at the page level (the admin page redirects unauthenticated users); these actions are only called from admin UI.

```ts
export async function getAllProducts(): Promise<Product[]>
// Returns all products ordered by display_order asc (including inactive, for admin view)

export async function addProduct(data: ProductFormData): Promise<void>

export async function updateProduct(id: string, data: ProductFormData): Promise<void>

export async function deleteProduct(id: string): Promise<void>

export async function toggleProductActive(id: string, active: boolean): Promise<void>

export async function reorderProducts(orderedIds: string[]): Promise<void>
// Updates display_order for each id: index * 10
```

`ProductFormData` type:
```ts
type ProductFormData = {
  name: string
  sku: string
  description: string
  price_label: string
  image_url: string
  buy_url: string
  category: 'kit' | 'merch'
  active: boolean
}
```
